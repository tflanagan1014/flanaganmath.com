Lesson 16: The Second Derivative Test

  • A relative minimum occurs at a critical point where the graph is concave up.
  • A relative maximum occurs at a critical point where the graph is concave down.
  • A horizontal tangent line does not guarantee an extremum. A critical point can be an inflection point instead.

The Second Derivative Test

\[ \begin{aligned} &\text{If } f'(c) = 0 \text{ and } f''(c) > 0, \text{ relative minimum at } c. \\ &\text{If } f'(c) = 0 \text{ and } f''(c) < 0, \text{ relative maximum at } c. \\ &\text{If } f''(c) = 0, \text{ the test is inconclusive.} \end{aligned} \]

Use the second derivative test to find and classify the extrema of \(f(x) = x^4 - 32x^2 + 30\).

\[ \begin{aligned} f'(x) &= 4x^3 - 64x \\ &= 4x(x - 4)(x + 4) \end{aligned} \]

The critical numbers are \(0\), \(4\), and \(-4\).

\[ \begin{aligned} f''(x) &= 12x^2 - 64 \\ f''(0) &= -64 < 0 \\ f''(\pm 4) &= 128 > 0 \end{aligned} \]
\[ \begin{aligned} f(0) &= 30 \\ f(\pm 4) &= 256 - 512 + 30 = -226 \end{aligned} \]

There is a relative maximum at \((0, 30)\), and minimums at \((-4, -226)\) and \((4, -226)\). Since the graph rises forever on both sides, those two minimums are also absolute minimums.

Each function below is everywhere twice differentiable.

If \(f\,'(5) = 0\) and \(f\,''(5) = 12\), what can you conclude at \(x = 5\)?

There is a horizontal tangent and the graph is concave up, so there is a relative (or absolute) minimum at \(x = 5\).

If \(f\,'(-2) = -53\) and \(f\,''(-2) = 71\), what can you conclude at \(x = -2\)?

The function is decreasing and concave up at \(x = -2\).

If \(f\,'(8) = 12\) and \(f\,''(8) = -12\), what can you conclude at \(x = 8\)?

The function is increasing and concave down at \(x = 8\).
