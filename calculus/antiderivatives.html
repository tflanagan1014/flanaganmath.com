Lesson 32: Antiderivatives

An antiderivative of \(f(x)\) is a function \(F(x)\) whose derivative is \(f(x)\). Since the derivative of a constant is zero, we add \(+\,C\) to get all antiderivatives.

The Integral Sign

\[ \int f(x)\,dx = F(x) + C \quad\text{means}\quad F'(x) = f(x) \]

Find all antiderivatives of \(f(x) = 3x^2\).

\[ \int 3x^2\,dx = x^3 + C \]

Check: \(\frac{d}{dx}\left[x^3 + C\right] = 3x^2\).

Basic Antiderivatives

\[ \begin{aligned} \int x^n\,dx &= \frac{x^{n + 1}}{n + 1} + C,\ n \neq -1 \\ \int \frac{1}{x}\,dx &= \ln|x| + C \\ \int e^x\,dx &= e^x + C \\ \int \cos x\,dx &= \sin x + C \\ \int \sin x\,dx &= -\cos x + C \\ \int \sec^2 x\,dx &= \tan x + C \\ \int \sec x\tan x\,dx &= \sec x + C \\ \int \frac{1}{1 + x^2}\,dx &= \tan^{-1} x + C \\ \int \frac{1}{\sqrt{1 - x^2}}\,dx &= \sin^{-1} x + C \end{aligned} \]

The Sum and Constant Multiple Rules

\[ \begin{aligned} &\int [f(x) \pm g(x)]\,dx = \int f(x)\,dx \pm \int g(x)\,dx \\ &\int c\,f(x)\,dx = c\int f(x)\,dx \end{aligned} \]

Every rule on this page will be on the final exam.

Find \(\displaystyle\int \left(3x^2 - 4x + 5\right)dx\).

\[ \int \left(3x^2 - 4x + 5\right)dx = x^3 - 2x^2 + 5x + C \]

Find \(\displaystyle\int \sqrt{x}\,dx\).

\[ \begin{aligned} \int x^{\frac{1}{2}}\,dx &= \frac{x^{\frac{3}{2}}}{\frac{3}{2}} + C \\ &= \frac{2}{3}x^{\frac{3}{2}} + C \end{aligned} \]

Find \(\displaystyle\int \left(4e^x - \frac{2}{x} + \cos x\right)dx\).

\[ \int \left(4e^x - \frac{2}{x} + \cos x\right)dx = 4e^x - 2\ln|x| + \sin x + C \]

A condition like \(y(1) = 5\) tells us which antiderivative we want. It lets us find \(C\).

Solve \(\dfrac{dy}{dx} = 6x^2\) with \(y(1) = 5\).

\[ \begin{aligned} y &= \int 6x^2\,dx = 2x^3 + C \\ 5 &= 2(1)^3 + C \\ C &= 3 \end{aligned} \]

The solution is \(y = 2x^3 + 3\).

Because \(v(t)\) is the derivative of \(s(t)\), position is an antiderivative of velocity. Likewise, velocity is an antiderivative of acceleration.

Motion and Antiderivatives

\[ \begin{aligned} &s(t) = \int v(t)\,dt \\ &v(t) = \int a(t)\,dt \end{aligned} \]

A Sample Final Exam Problem

An object has acceleration \(a(t) = -32\), with \(v(0) = 9\) and \(s(0) = 10\). Find its position \(s(t)\).

\[ \begin{aligned} v(t) &= \int -32\,dt = -32t + C_1 \\ 9 &= C_1 \end{aligned} \]
\[ \begin{aligned} s(t) &= \int (-32t + 9)\,dt = -16t^2 + 9t + C_2 \\ 10 &= C_2 \end{aligned} \]

So \(s(t) = -16t^2 + 9t + 10\).
