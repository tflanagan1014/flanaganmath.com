Lesson 55: Sequences

Think of a sequence as an infinite list, like \(1, 1, 2, 3, 5, 8, 13, 21, \ldots\) More precisely, a sequence is a function whose domain is the positive integers.

Find the first three terms of \(\displaystyle\left\{s_n\right\}_1^\infty = \frac{(-1)^n}{(n + 2)!}\).

\[ \begin{aligned} s_1 &= \frac{-1}{3!} = -\frac{1}{6} \\ s_2 &= \frac{1}{4!} = \frac{1}{24} \\ s_3 &= \frac{-1}{5!} = -\frac{1}{120} \end{aligned} \]

Find the 100th term of \(\displaystyle\left\{s_n\right\}_1^\infty = 8 + \frac{2}{n}\).

\[ \begin{aligned} s_{100} &= 8 + \frac{2}{100} \\ &= 8.02 \end{aligned} \]

Find the limit of \(\displaystyle\left\{s_n\right\}_1^\infty = \frac{9n + 17}{2n - 13}\), or state that it is divergent.

\[ \begin{aligned} \lim_{n \to \infty} \frac{9n + 17}{2n - 13} &= \lim_{n \to \infty} \frac{9 + \frac{17}{n}}{2 - \frac{13}{n}} \\ &= \frac{9}{2} \end{aligned} \]

Find the limit of \(\left\{s_n\right\}_1^\infty = 2 + n^2\), or state that it is divergent.

The terms grow without bound, so the sequence is divergent.

  • Bounded above: there is a number \(M\) with \(s_n \le M\) for all \(n\). Example: \(10 - \frac{1}{n^2}\) is bounded above by 10.
  • Bounded below: there is a number \(m\) with \(s_n \ge m\) for all \(n\). Example: \(10 + \frac{1}{n^2}\) is bounded below by 10.
  • Increasing: \(s_n < s_{n+1}\) for all \(n\). Example: \(1 + n^2\).
  • Decreasing: \(s_n > s_{n+1}\) for all \(n\). Example: \(\frac{1}{n^2}\).
  • Nondecreasing: \(s_n \le s_{n+1}\) for all \(n\). Example: \(1, 1, 2, 2, 3, 3, \ldots\)
  • Nonincreasing: \(s_n \ge s_{n+1}\) for all \(n\). Example: \(\frac{1}{2}, \frac{1}{2}, \frac{1}{4}, \frac{1}{4}, \frac{1}{8}, \frac{1}{8}, \ldots\)

A sequence is monotonic if it is increasing, decreasing, nondecreasing, or nonincreasing. It never switches direction.

An Important Theorem

\[ \text{A bounded, monotonic sequence converges.} \]

If a sequence always moves in one direction and stays within fixed limits, it cannot keep going forever without settling down.
