Lesson 43: Work

When a constant force \(F\) moves an object a distance \(d\), the work done is \(W = Fd\). But many forces are not constant. Gravity and electromagnetic forces depend on distance from the source.

Divide the motion into tiny intervals of length \(\Delta x\). Over each one the force is nearly constant, so \(\Delta W \approx F(x_k)\,\Delta x\).

\[ W = \lim_{n \to \infty} \sum_{k=1}^{n} F(x_k)\,\Delta x \]

Work Done by a Variable Force

\[ W = \int_a^b F(x)\,dx \]

An object is attracted to a point source by a force, in newtons, of \(F(x) = -\dfrac{15}{x^2}\), where \(x\) is the distance in meters. Find the work done as the object moves from \(x = 20\) to \(x = 10\) meters.

\[ \begin{aligned} W &= \int_{20}^{10} -\frac{15}{x^2}\,dx \\ &= \left[\frac{15}{x}\right]_{20}^{10} \\ &= \frac{15}{10} - \frac{15}{20} \\ &= 0.75 \end{aligned} \]

The work done is 0.75 joules.
