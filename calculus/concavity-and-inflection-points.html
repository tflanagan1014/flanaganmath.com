Lesson 28: Concavity and Inflection Points

A twice differentiable function is concave up where \(f\,''(x) > 0\) and concave down where \(f\,''(x) < 0\). An inflection point is a point on the graph where the concavity changes.

Steps

  1. Find the numbers where \(f\,''(x)\) is zero or undefined.
  2. Use them to break up the number line into intervals.
  3. Choose a test number in each interval and find the sign of \(f\,''(x)\).
  4. Concave up where \(f\,''(x)\) is positive, concave down where it is negative.
  5. Where the concavity changes, find the \(y\)-coordinate with \(f(x)\). That is an inflection point.

Find where the function below is concave up and down, and find any inflection points.

\[ f(x) = -x^4 - 4x^3 + 210x^2 - 43x + 85 \]
\[ \begin{aligned} f'(x) &= -4x^3 - 12x^2 + 420x - 43 \\ f''(x) &= -12x^2 - 24x + 420 \\ &= -12(x + 7)(x - 5) \end{aligned} \]
Signs of the second derivative
Interval\(f\,''(x)\)Concave
\((-\infty, -7)\)−down
\((-7, 5)\)+up
\((5, \infty)\)−down
\[ \begin{aligned} f(-7) &= 9647 \\ f(5) &= 3995 \end{aligned} \]

The inflection points are \((-7, 9647)\) and \((5, 3995)\).

A Sample Exam Problem

On \((0, 2\pi)\), find where \(f(x) = 7 + x^2 + \cos(2x)\) is concave up and concave down.

\[ \begin{aligned} f'(x) &= 2x - 2\sin(2x) \\ f''(x) &= 2 - 4\cos(2x) \end{aligned} \]

\(f\,''(x) > 0\) when \(\cos(2x) < \frac{1}{2}\). For \(0 < 2x < 4\pi\), that happens when \(\frac{\pi}{3} < 2x < \frac{5\pi}{3}\) or \(\frac{7\pi}{3} < 2x < \frac{11\pi}{3}\).

Concave up on \(\left(\frac{\pi}{6}, \frac{5\pi}{6}\right)\) and \(\left(\frac{7\pi}{6}, \frac{11\pi}{6}\right)\).

Concave down on \(\left(0, \frac{\pi}{6}\right)\), \(\left(\frac{5\pi}{6}, \frac{7\pi}{6}\right)\), and \(\left(\frac{11\pi}{6}, 2\pi\right)\).
