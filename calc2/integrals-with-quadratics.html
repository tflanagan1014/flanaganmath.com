Lesson 17: Integrals Containing Quadratics

A Rule from Calculus 1

\[ \int \frac{du}{u^2 + a^2} = \frac{1}{a}\tan^{-1}\left(\frac{u}{a}\right) + C \]

Evaluate \(\displaystyle \int \frac{dx}{x^2 + 4x + 104}\).

\[ \int \frac{dx}{(x + 2)^2 + 100} = \frac{1}{10}\tan^{-1}\left(\frac{x + 2}{10}\right) + C \]

Try to rewrite the numerator to include the derivative of the denominator. Then use \(\displaystyle\int \frac{du}{u} = \ln|u| + C\).

Evaluate \(\displaystyle \int \frac{x^2}{x^2 + 1}\,dx\).

\[ \begin{aligned} \int \frac{x^2}{x^2 + 1}\,dx &= \int \left(1 - \frac{1}{x^2 + 1}\right)dx \\ &= x - \tan^{-1} x + C \end{aligned} \]

Evaluate \(\displaystyle \int \frac{x}{x^2 + 2x + 50}\,dx\).

The derivative of the denominator is \(2x + 2\). Write \(x = \frac{1}{2}(2x + 2) - 1\).

\[ \begin{aligned} &\int \frac{x}{x^2 + 2x + 50}\,dx \\ &\quad = \frac{1}{2}\int \frac{2x + 2}{x^2 + 2x + 50}\,dx - \int \frac{dx}{(x + 1)^2 + 49} \\ &\quad = \frac{1}{2}\ln\left(x^2 + 2x + 50\right) - \frac{1}{7}\tan^{-1}\left(\frac{x + 1}{7}\right) + C \end{aligned} \]

Evaluate \(\displaystyle \int \frac{3x + 8}{x^2 + 4x + 13}\,dx\).

Write \(3x + 8 = \frac{3}{2}(2x + 4) + 2\).

\[ \begin{aligned} &\int \frac{3x + 8}{x^2 + 4x + 13}\,dx \\ &\quad = \frac{3}{2}\int \frac{2x + 4}{x^2 + 4x + 13}\,dx + 2\int \frac{dx}{(x + 2)^2 + 9} \\ &\quad = \frac{3}{2}\ln\left(x^2 + 4x + 13\right) + \frac{2}{3}\tan^{-1}\left(\frac{x + 2}{3}\right) + C \end{aligned} \]
