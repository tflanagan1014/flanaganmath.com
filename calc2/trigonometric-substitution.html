Lesson 16: Trigonometric Substitution

  • If the integrand contains \(\sqrt{a^2 - x^2}\), let \(x = a\sin\theta\). Use \(1 - \sin^2\theta = \cos^2\theta\).
  • If the integrand contains \(\sqrt{x^2 + a^2}\), let \(x = a\tan\theta\). Use \(\tan^2\theta + 1 = \sec^2\theta\).
  • If the integrand contains \(\sqrt{x^2 - a^2}\), let \(x = a\sec\theta\). Use \(\sec^2\theta - 1 = \tan^2\theta\).

After integrating, draw a right triangle to change back to x.

Evaluate \(\displaystyle \int \frac{dx}{x^2\sqrt{100 - x^2}}\).

Let \(x = 10\sin\theta\), so \(dx = 10\cos\theta\,d\theta\) and \(\sqrt{100 - x^2} = 10\cos\theta\).

\[ \begin{aligned} \int \frac{10\cos\theta\,d\theta}{100\sin^2\theta \cdot 10\cos\theta} &= \frac{1}{100}\int \csc^2\theta\,d\theta \\ &= -\frac{\cot\theta}{100} + C \\ &= -\frac{\sqrt{100 - x^2}}{100x} + C \end{aligned} \]

Evaluate \(\displaystyle \int \frac{dx}{\left(x^2 + 121\right)^{3/2}}\).

Let \(x = 11\tan\theta\), so \(dx = 11\sec^2\theta\,d\theta\) and \(\left(x^2 + 121\right)^{3/2} = 1331\sec^3\theta\).

\[ \begin{aligned} \int \frac{11\sec^2\theta\,d\theta}{1331\sec^3\theta} &= \frac{1}{121}\int \cos\theta\,d\theta \\ &= \frac{\sin\theta}{121} + C \\ &= \frac{x}{121\sqrt{x^2 + 121}} + C \end{aligned} \]

Evaluate \(\displaystyle \int \frac{\sqrt{x^2 - 1}}{x}\,dx\).

Let \(x = \sec\theta\), so \(dx = \sec\theta\tan\theta\,d\theta\) and \(\sqrt{x^2 - 1} = \tan\theta\).

\[ \begin{aligned} \int \frac{\tan\theta}{\sec\theta}\sec\theta\tan\theta\,d\theta &= \int \tan^2\theta\,d\theta \\ &= \int \left(\sec^2\theta - 1\right)d\theta \\ &= \tan\theta - \theta + C \\ &= \sqrt{x^2 - 1} - \sec^{-1} x + C \end{aligned} \]
