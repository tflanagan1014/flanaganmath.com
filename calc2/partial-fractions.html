Lesson 19: Partial Fraction Decomposition

Partial fractions rewrite a complicated rational expression as a sum of simpler fractions that are easy to integrate.

Write one constant numerator over each linear factor.

Evaluate \(\displaystyle \int \frac{x}{x^2 - 10x + 21}\,dx\).

\[ \begin{aligned} \frac{x}{(x - 3)(x - 7)} &= \frac{A}{x - 3} + \frac{B}{x - 7} \\ x &= A(x - 7) + B(x - 3) \end{aligned} \]

At \(x = 3\): \(3 = -4A\), so \(A = -\frac{3}{4}\). At \(x = 7\): \(7 = 4B\), so \(B = \frac{7}{4}\).

\[ \int \frac{x}{x^2 - 10x + 21}\,dx = -\frac{3}{4}\ln|x - 3| + \frac{7}{4}\ln|x - 7| + C \]

Evaluate \(\displaystyle \int \frac{dx}{x^2 - 36}\).

\[ \frac{1}{(x - 6)(x + 6)} = \frac{1}{12}\left(\frac{1}{x - 6} - \frac{1}{x + 6}\right) \]
\[ \int \frac{dx}{x^2 - 36} = \frac{1}{12}\ln\left|\frac{x - 6}{x + 6}\right| + C \]

Include one fraction for each power of the repeated factor.

Evaluate \(\displaystyle \int \frac{dx}{x^3 - 10x^2 + 25x}\).

\[ \begin{aligned} \frac{1}{x(x - 5)^2} &= \frac{A}{x} + \frac{B}{x - 5} + \frac{C}{(x - 5)^2} \\ 1 &= A(x - 5)^2 + Bx(x - 5) + Cx \end{aligned} \]

At \(x = 0\): \(A = \frac{1}{25}\). At \(x = 5\): \(C = \frac{1}{5}\). Matching \(x^2\) terms: \(A + B = 0\), so \(B = -\frac{1}{25}\).

\[ \begin{aligned} &\int \frac{dx}{x^3 - 10x^2 + 25x} \\ &\quad = \frac{1}{25}\ln|x| - \frac{1}{25}\ln|x - 5| - \frac{1}{5(x - 5)} + C \end{aligned} \]

Use a linear numerator over a quadratic that does not factor.

Evaluate \(\displaystyle \int \frac{3x + 5}{(x - 1)\left(x^2 + 4\right)}\,dx\).

\[ \begin{aligned} \frac{3x + 5}{(x - 1)\left(x^2 + 4\right)} &= \frac{A}{x - 1} + \frac{Bx + C}{x^2 + 4} \\ 3x + 5 &= A\left(x^2 + 4\right) + (Bx + C)(x - 1) \end{aligned} \]

At \(x = 1\): \(8 = 5A\), so \(A = \frac{8}{5}\). Matching \(x^2\) terms: \(B = -\frac{8}{5}\). Matching constants: \(5 = 4A - C\), so \(C = \frac{7}{5}\).

\[ \begin{aligned} &\int \frac{3x + 5}{(x - 1)\left(x^2 + 4\right)}\,dx \\ &\quad = \frac{8}{5}\ln|x - 1| - \frac{4}{5}\ln\left(x^2 + 4\right) + \frac{7}{10}\tan^{-1}\left(\frac{x}{2}\right) + C \end{aligned} \]

Include a linear numerator over each power of the repeated quadratic.

Evaluate \(\displaystyle \int \frac{x^3 + 216}{\left(x^2 + 36\right)^2}\,dx\).

\[ \frac{x^3 + 216}{\left(x^2 + 36\right)^2} = \frac{Ax + B}{x^2 + 36} + \frac{Cx + D}{\left(x^2 + 36\right)^2} \]

Matching coefficients gives \(A = 1\), \(B = 0\), \(C = -36\), and \(D = 216\).

\[ \begin{aligned} &\int \frac{x}{x^2 + 36}\,dx = \frac{1}{2}\ln\left(x^2 + 36\right) \\ &\int \frac{-36x}{\left(x^2 + 36\right)^2}\,dx = \frac{18}{x^2 + 36} \end{aligned} \]

For the last piece, let \(x = 6\tan\theta\).

\[ \begin{aligned} \int \frac{216\,dx}{\left(x^2 + 36\right)^2} &= \int \cos^2\theta\,d\theta \\ &= \frac{\theta}{2} + \frac{\sin\theta\cos\theta}{2} \\ &= \frac{1}{2}\tan^{-1}\left(\frac{x}{6}\right) + \frac{3x}{x^2 + 36} \end{aligned} \]
\[ \begin{aligned} &\int \frac{x^3 + 216}{\left(x^2 + 36\right)^2}\,dx \\ &\quad = \frac{1}{2}\ln\left(x^2 + 36\right) + \frac{3x + 18}{x^2 + 36} + \frac{1}{2}\tan^{-1}\left(\frac{x}{6}\right) + C \end{aligned} \]
