Numerical Integration

Some integrals cannot be evaluated exactly. For a continuous function on \([a, b]\), partition the interval into \(n\) equal subintervals of width \(\Delta x = \frac{b - a}{n}\), with \(x_k = a + k\,\Delta x\).

The Trapezoidal Rule

\[ \begin{aligned} &\int_a^b f(x)\,dx \approx \frac{\Delta x}{2}\Big[f(x_0) + 2f(x_1) + 2f(x_2) \\ &\qquad + \cdots + 2f(x_{n-1}) + f(x_n)\Big] \end{aligned} \]

The Midpoint Rule

\[ \begin{aligned} &\int_a^b f(x)\,dx \approx \Delta x\left[f\left(x_1^*\right) + \cdots + f\left(x_n^*\right)\right] \\ &\qquad\text{where } x_k^* = a + \left(k - \tfrac{1}{2}\right)\Delta x \end{aligned} \]

Simpson’s Rule (n even)

\[ \begin{aligned} &\int_a^b f(x)\,dx \approx \frac{\Delta x}{3}\Big[f(x_0) + 4f(x_1) + 2f(x_2) \\ &\qquad + 4f(x_3) + \cdots + 4f(x_{n-1}) + f(x_n)\Big] \end{aligned} \]

Approximate \(\displaystyle\int_0^2 x^2\,dx\) with \(n = 4\) using each rule. The exact value is \(\frac{8}{3} \approx 2.6667\).

\(\Delta x = 0.5\). The points are \(0, 0.5, 1, 1.5, 2\), with \(f\) values \(0, 0.25, 1, 2.25, 4\).

\[ \begin{aligned} \text{Trapezoidal} &= \frac{0.5}{2}\left[0 + 2(0.25) + 2(1) + 2(2.25) + 4\right] \\ &= 2.75 \end{aligned} \]
\[ \begin{aligned} \text{Midpoint} &= 0.5\left[f(0.25) + f(0.75) + f(1.25) + f(1.75)\right] \\ &= 0.5(0.0625 + 0.5625 + 1.5625 + 3.0625) \\ &= 2.625 \end{aligned} \]
\[ \begin{aligned} \text{Simpson} &= \frac{0.5}{3}\left[0 + 4(0.25) + 2(1) + 4(2.25) + 4\right] \\ &= \frac{8}{3} \end{aligned} \]

Simpson’s Rule is exact here, because it is exact for polynomials up to degree three.
