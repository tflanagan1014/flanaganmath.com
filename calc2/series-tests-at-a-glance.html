Series Tests at a Glance

Know all of this for the exam. No notes are allowed!

p-Series

\[ \sum_{k=1}^{\infty} \frac{1}{k^p}\ \text{converges if } p > 1,\ \text{diverges if } p \le 1 \]

The Harmonic Series

\[ \sum_{k=1}^{\infty} \frac{1}{k}\ \text{diverges} \]

Geometric Series

\[ \sum_{k=1}^{\infty} ar^{k - 1} = \frac{a}{1 - r} \ \text{if } |r| < 1;\ \text{diverges if } |r| \ge 1 \]

The Divergence Test

\[ \lim_{n \to \infty} a_n \neq 0 \implies \text{diverges} \]

The Integral Test

\[ \sum a_k \text{ and } \int_1^\infty f(x)\,dx \text{ both converge or both diverge} \]

The Direct Comparison Test

\[ \begin{aligned} &0 \le a_n \le b_n,\ \textstyle\sum b_k \text{ converges} \implies \textstyle\sum a_k \text{ converges} \\ &0 \le b_n \le a_n,\ \textstyle\sum b_k \text{ diverges} \implies \textstyle\sum a_k \text{ diverges} \end{aligned} \]

The Limit Comparison Test

\[ 0 < \lim_{n \to \infty} \frac{a_n}{b_n} < \infty \implies \text{same behavior} \]

The Alternating Series Test

\[ |a_n| \text{ decreasing},\ |a_n| \to 0 \implies \text{converges} \]

The Ratio and Root Tests

\[ L = \lim \left|\frac{a_{n+1}}{a_n}\right| \text{ or } \lim \sqrt[n]{|a_n|}: \quad L < 1 \text{ converges},\ L > 1 \text{ diverges} \]

Sequences

\[ \text{Bounded and monotonic} \implies \text{converges} \]
