Conservative Vector Fields

A vector field \(\mathbf{F}\) is conservative if there exists a scalar-valued function \(f\) such that \(\nabla f = \mathbf{F}\). In this case, we call \(f\) a potential function for \(\mathbf{F}\).

Conservative Vector Field

\[ \mathbf{F} = \nabla f \]

An Example

Show that the vector field below is conservative, with the potential function \(f(x, y) = x + y^2 + 4\).

\[ \mathbf{F} = \langle 1,\ 2y \rangle \]
\[ \begin{aligned} \nabla f &= \left\langle \frac{\partial f}{\partial x},\ \frac{\partial f}{\partial y} \right\rangle \\ &= \langle 1,\ 2y \rangle \\ &= \mathbf{F} \end{aligned} \]

Since \(\nabla f = \mathbf{F}\), the vector field is conservative, and \(f\) is a potential function for it.

Given a conservative vector field \(\mathbf{F}(x, y) = P(x, y)\,\mathbf{i} + Q(x, y)\,\mathbf{j}\):

  1. Integrate \(P\) with respect to \(x\). Add a function \(g(y)\) instead of a constant, since anything that depends only on \(y\) is constant with respect to \(x\). \(\displaystyle f = \int P\,dx + g(y)\)
  2. Differentiate your result with respect to \(y\), and set it equal to \(Q\).
  3. Solve for \(g(y)\), and substitute it back into \(f\).

An Example

Find a potential function for the vector field below.

\[ \mathbf{F}(x, y) = \langle 2xy,\ x^2 + 3y^2 \rangle \]

Here \(P = 2xy\) and \(Q = x^2 + 3y^2\).

Step 1: Integrate \(P\) with respect to \(x\).

\[ \begin{aligned} f &= \int 2xy\,dx + g(y) \\ &= x^2 y + g(y) \end{aligned} \]

Step 2: Differentiate with respect to \(y\), and set it equal to \(Q\).

\[ \frac{\partial f}{\partial y} = x^2 + g'(y) = x^2 + 3y^2 \]

Step 3: Solve for \(g(y)\), and substitute it back into \(f\).

\[ g'(y) = 3y^2 \]
\[ g(y) = y^3 + C \]
\[ f(x, y) = x^2 y + y^3 + C \]
