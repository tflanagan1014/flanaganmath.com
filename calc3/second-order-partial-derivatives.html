Lesson 18: Second-Order Partial Derivatives

Given a function of two variables \(f(x, y)\), the second-order partial derivatives and their notations are explained below.

NotationMeaning
\(\dfrac{\partial^2 f}{\partial x^2} = f_{xx}\)Treat \(y\) as a constant and differentiate twice with respect to \(x\).
\(\dfrac{\partial^2 f}{\partial y^2} = f_{yy}\)Treat \(x\) as a constant and differentiate twice with respect to \(y\).
\(\dfrac{\partial^2 f}{\partial y\,\partial x} = f_{xy}\)Differentiate with respect to \(x\), and then with respect to \(y\).
\(\dfrac{\partial^2 f}{\partial x\,\partial y} = f_{yx}\)Differentiate with respect to \(y\), and then with respect to \(x\).

The last two, \(f_{xy}\) and \(f_{yx}\), are called the mixed partial derivatives.

An Example

Given the function below, find \(f_{xx}\).

\[ f(x, y) = x^5 + xy + 7x - e^y - 10 \]
\[ f_x = 5x^4 + y + 7 \]
\[ f_{xx} = 20x^3 \]

An Example

Given the function below, find each of the following.

\[ f(x, y) = 100 + \sin x + e^y + 2x^4 y^5 \]

\(\dfrac{\partial f}{\partial x}\), \(\dfrac{\partial^2 f}{\partial y\,\partial x}\), \(\dfrac{\partial f}{\partial y}\), and \(\dfrac{\partial^2 f}{\partial x\,\partial y}\)

\[ \frac{\partial f}{\partial x} = \cos x + 8x^3 y^5 \]
\[ \frac{\partial^2 f}{\partial y\,\partial x} = 40x^3 y^4 \]
\[ \frac{\partial f}{\partial y} = e^y + 10x^4 y^4 \]
\[ \frac{\partial^2 f}{\partial x\,\partial y} = 40x^3 y^4 \]

Notice the two mixed partial derivatives are equal.

If the mixed partial derivatives \(f_{xy}\) and \(f_{yx}\) are continuous on an open region, then they are equal there. This is called Clairaut’s Theorem.

Clairaut's Theorem

\[ f_{xy} = f_{yx} \]

Notice this happened in the previous example. This will come up in the online homework.
