Problem 1

The graph of \(f\) is shown below. Each tick mark represents \(1\) unit. The asymptote is shown as a dotted line.

If something does not exist, write “none.”

  1. Equation of the asymptote
  2. Domain
  3. Range
  4. \(x\)-intercept(s)
  5. \(y\)-intercept
  6. \(f(-5)\), \(f(-2)\), and \(f(0)\)
  7. Maximum value
  8. Where it occurs
  9. Minimum value
  10. Where it occurs

Before answering, trace the graph from left to right. It starts at the filled point \((-5,\,-2)\), rises in a straight line to \((-2,\,4)\), falls in a straight line to \((0,\,2)\), and then curves down toward the dotted line, getting closer and closer to it forever. The arrow on the right end means the graph keeps going to the right.

  1. Asymptote: \(y = 1\). The dotted line is horizontal and sits at height \(1\). A horizontal line is named by its \(y\)-value, so its equation is \(y = 1\).
  2. Domain: \([-5,\,\infty)\). Read the \(x\)-values from left to right. The graph starts at \(x = -5\), and that point is a filled circle, so \(-5\) is included and gets a square bracket. The arrow on the right means the graph goes on forever to the right, so the domain ends at \(\infty\).
  3. Range: \([-2,\,4]\). Read the \(y\)-values from bottom to top. The lowest point is the filled endpoint at height \(-2\), and the highest point is the peak at height \(4\). Both are included, so both get square brackets. The curve on the right drops toward \(y = 1\) but never reaches it. That does not change the range, because every height between \(1\) and \(2\) is already covered by the straight-line parts of the graph.
  4. \(x\)-intercept: \((-4,\,0)\). The graph crosses the \(x\)-axis only once, on the rising line at \(x = -4\). Remember to write an intercept as an ordered pair.
  5. \(y\)-intercept: \((0,\,2)\). The graph crosses the \(y\)-axis at height \(2\).
  6. \(f(-5) = -2\), \(f(-2) = 4\), \(f(0) = 2\). To find \(f(a)\), go to \(x = a\) and find the height of the graph there. At \(x = -5\) the graph is at height \(-2\), at \(x = -2\) it is at height \(4\), and at \(x = 0\) it is at height \(2\).
  7. Maximum value: \(4\). The maximum value is the highest \(y\)-value the graph reaches, which is the top of the peak.
  8. It occurs at \(x = -2\). The maximum is a \(y\)-value, but “where it occurs” asks for the \(x\)-value of that highest point.
  9. Minimum value: \(-2\). The lowest point on the graph is the filled endpoint. Since the point is filled, the graph really reaches height \(-2\).
  10. It occurs at \(x = -5\). The lowest point is at the left endpoint, \((-5,\,-2)\).

Problem 10

Find all intercepts. State each one as an ordered pair.

\[ h(x) = \log_2(x^2 - 2x) - 3 \]

Show all of your work.

\(y\)-intercept. The \(y\)-intercept is where \(x = 0\), so find \(h(0)\).

\[ h(0) = \log_2(0^2 - 2\cdot 0) - 3 = \log_2(0) - 3 \]

We can only take the log of a positive number. \(\log_2 0\) is undefined, so \(x = 0\) is not in the domain, and there is no \(y\)-intercept.

\(x\)-intercepts. The \(x\)-intercepts are where the output is \(0\), so set \(h(x) = 0\). First get the log by itself, by adding \(3\) to both sides.

\[ \begin{aligned} \log_2(x^2-2x)-3 &= 0 \\ \log_2(x^2-2x) &= 3 \end{aligned} \]

Now rewrite the log equation in exponential form. \(\log_2(\text{something}) = 3\) means \(2^3 = \text{something}\).

\[ \begin{aligned} x^2-2x &= 2^3 \\ x^2-2x &= 8 \end{aligned} \]

This is a quadratic equation. Move everything to one side so it equals \(0\), and factor.

\[ \begin{aligned} x^2-2x-8 &= 0 \\ (x-4)(x+2) &= 0 \end{aligned} \]

Set each factor equal to \(0\): \(x - 4 = 0\) gives \(x = 4\), and \(x + 2 = 0\) gives \(x = -2\).

Check. The argument of the log, \(x^2 - 2x\), must be positive. For \(x = 4\): \(16 - 8 = 8\), which is positive. For \(x = -2\): \(4 + 4 = 8\), which is positive. Both solutions work. Notice that \(x = -2\) is fine even though it is negative. What matters is that the argument of the log is positive, not \(x\) itself.

\(x\)-intercepts: \((4,\,0)\) and \((-2,\,0)\). \(y\)-intercept: none.

Problem 11

Determine whether the function is even, odd, or neither.

\[ h(x) = x^5 - 3x^3 \]

Show all of your work.

To test for even or odd, replace \(x\) with \(-x\) and simplify. Then compare \(h(-x)\) with \(h(x)\).

  • If \(h(-x) = h(x)\), the function is even.
  • If \(h(-x) = -h(x)\), the function is odd.
  • If neither is true, the function is neither.
\[ \begin{aligned} h(-x) &= (-x)^5-3(-x)^3 \\ &= -x^5-3(-x^3) \\ &= -x^5+3x^3 \end{aligned} \]

A negative number raised to an odd power stays negative, so \((-x)^5 = -x^5\) and \((-x)^3 = -x^3\).

The result \(-x^5 + 3x^3\) is not the same as \(h(x) = x^5 - 3x^3\), so the function is not even. Every sign has flipped, though, so factor out a negative:

\[ \begin{aligned} h(-x) &= -(x^5-3x^3) \\ &= -h(x) \end{aligned} \]

Since \(h(-x) = -h(x)\), the function is odd.

\(f(x) = x^2\) is shifted right 3, then reflected across the \(x\)-axis, and then shifted up 2.

Apply the transformations one at a time, in the order given.

Shifted right 3. A horizontal shift changes the inside of the function. Shifting right 3 replaces \(x\) with \(x - 3\). It is a minus, even though the shift is to the right.

\[ (x-3)^2 \]

Then reflected across the \(x\)-axis. A reflection across the \(x\)-axis turns every output into its opposite, so put a negative in front of the whole function.

\[ -(x-3)^2 \]

And then shifted up 2. A vertical shift changes the outside of the function. Shifting up 2 adds \(2\) to the whole thing.

\[ g(x)=-(x-3)^2+2 \]

The order matters here. If we shifted up 2 before reflecting, the reflection would also flip the \(+2\), and we would get \(-(x-3)^2 - 2\), a different function.

Problem 13

Find and simplify the difference quotient for \(f(x) = 4x - 3x^2\).

Show all of your work.

The difference quotient is

\[ \frac{f(x+h)-f(x)}{h} \]

Step 1: find \(f(x+h)\). Replace every \(x\) in the formula with \(x + h\), in parentheses.

\[ f(x+h) = 4(x+h)-3(x+h)^2 \]

Square \(x + h\) first, before multiplying by \(-3\). Remember that \((x+h)^2 = x^2 + 2xh + h^2\), not \(x^2 + h^2\).

\[ \begin{aligned} f(x+h) &= 4x+4h-3(x^2+2xh+h^2) \\ &= 4x+4h-3x^2-6xh-3h^2 \end{aligned} \]

Step 2: subtract \(f(x)\). Put \(f(x)\) in parentheses so the subtraction reaches every term.

\[ \begin{aligned} f(x+h)-f(x) &= (4x+4h-3x^2-6xh-3h^2)-(4x-3x^2) \\ &= 4x+4h-3x^2-6xh-3h^2-4x+3x^2 \\ &= 4h-6xh-3h^2 \end{aligned} \]

The \(4x\) and \(-4x\) cancel, and the \(-3x^2\) and \(+3x^2\) cancel. Every term left has an \(h\) in it. That is a good sign that the work is right.

Step 3: divide by \(h\). Factor \(h\) out of the top, then cancel it with the \(h\) on the bottom.

\[ \begin{aligned} \frac{f(x+h)-f(x)}{h} &= \frac{4h-6xh-3h^2}{h} \\ &= \frac{h(4-6x-3h)}{h} \\ &= 4-6x-3h \end{aligned} \]

Problem 14

The number of bacteria in a culture follows the law of exponential growth. Initially there are \(500\) bacteria. After \(2\) hours there are \(1500\) bacteria.

Show all of your work.

  1. Find the value of \(k\). Round to four decimal places, and write the model \(A(t)\), where \(t\) is the number of hours.
  2. How many bacteria will there be after \(5\) hours? Round to the nearest whole number.
  3. How long will it take for there to be \(10{,}000\) bacteria? Round to two decimal places.

a. The law of exponential growth is \(A(t) = A_0 e^{kt}\), where \(A_0\) is the initial amount and \(k\) is the growth rate. Initially there are \(500\) bacteria, so \(A_0 = 500\):

\[ A(t) = 500e^{kt} \]

To find \(k\), use the other piece of information: after \(2\) hours there are \(1500\) bacteria. That means \(A(2) = 1500\). Put \(t = 2\) and \(A = 1500\) into the model.

\[ 1500 = 500e^{k\cdot 2} \]

Divide both sides by \(500\) to get the exponential part by itself.

\[ 3 = e^{2k} \]

The variable is in the exponent, so take the natural log of both sides. Since \(\ln e^{2k} = 2k\), this brings the exponent down.

\[ \begin{aligned} \ln 3 &= 2k \\ k &= \frac{\ln 3}{2} \\ k &\approx 0.5493 \end{aligned} \]

Put \(k\) back into the model:

\[ A(t)=500e^{0.5493t} \]

b. Put \(t = 5\) into the model.

\[ \begin{aligned} A(5) &= 500e^{0.5493(5)} \\ &= 500e^{2.7465} \\ &\approx 7794 \end{aligned} \]

There will be about \(7794\) bacteria after \(5\) hours. This makes sense: the population triples every \(2\) hours, so after \(4\) hours there are \(4500\), and after \(5\) hours there should be a good deal more.

c. This time we know the amount, \(A = 10{,}000\), and want the time \(t\). Set the model equal to \(10{,}000\).

\[ 10{,}000 = 500e^{0.5493t} \]

Divide both sides by \(500\), then take the natural log of both sides to bring the exponent down.

\[ \begin{aligned} 20 &= e^{0.5493t} \\ \ln 20 &= 0.5493t \\ t &= \frac{\ln 20}{0.5493} \\ t &\approx 5.45 \end{aligned} \]

It will take about \(5.45\) hours to reach \(10{,}000\) bacteria. This agrees with part b: at \(5\) hours there were about \(7794\), so reaching \(10{,}000\) a little after \(5\) hours makes sense.

Problem 15

Write the expression as a sum and/or difference of logarithms. Express powers as factors.

\[ \log\left(\dfrac{x^2\sqrt{x - 3}}{(x + 5)^3}\right) \]

Show all of your work.

Quotient rule. The log of a fraction is the log of the top minus the log of the bottom.

\[ = \log\left(x^2\sqrt{x-3}\right)-\log(x+5)^3 \]

Product rule. The top is a product, so its log splits into a sum. Also write the square root as the power \(\tfrac12\).

\[ = \log x^2+\log(x-3)^{1/2}-\log(x+5)^3 \]

Power rule. Bring each power down in front of its log as a factor.

\[ = 2\log x+\tfrac12\log(x-3)-3\log(x+5) \]

Notice that \(\log(x-3)\) cannot be split any further. There is no rule for the log of a difference.

Problem 16

Solve the equation.

\[ \log_2 x + \log_2(x - 2) = \log_2 15 \]

Show all of your work.

Use the product rule to combine the two logs on the left into one log.

\[ \log_2\big(x(x-2)\big) = \log_2 15 \]

Now there is a single log with the same base on each side. If \(\log_2 A = \log_2 B\), then \(A = B\), so set the arguments equal.

\[ \begin{aligned} x(x-2) &= 15 \\ x^2-2x &= 15 \end{aligned} \]

This is a quadratic equation. Move everything to one side and factor.

\[ \begin{aligned} x^2-2x-15 &= 0 \\ (x-5)(x+3) &= 0 \end{aligned} \]

So \(x = 5\) or \(x = -3\).

Check both in the original equation. We can only take the log of a positive number.

\(x = -3\): the first term would be \(\log_2(-3)\), which is undefined. So \(x = -3\) is a false solution and must be thrown out.

\(x = 5\): \(\log_2 5 + \log_2 3 = \log_2(5\cdot 3) = \log_2 15\). It checks.

The solution is \(x = 5\).

Problem 17

Solve.

\[ 2x^4 = 50x^2 \]

Show all of your work.

It is tempting to divide both sides by \(x^2\), but don't. Dividing by \(x^2\) assumes \(x \ne 0\), and that would lose the solution \(x = 0\). Instead, move everything to one side so the equation equals \(0\).

\[ 2x^4-50x^2 = 0 \]

Factor out the greatest common factor, \(2x^2\).

\[ 2x^2(x^2-25) = 0 \]

The factor \(x^2 - 25\) is a difference of squares, so it factors as \((x-5)(x+5)\).

\[ 2x^2(x-5)(x+5) = 0 \]

Set each factor equal to \(0\). From \(2x^2 = 0\), we get \(x = 0\). From \(x - 5 = 0\), we get \(x = 5\). From \(x + 5 = 0\), we get \(x = -5\).

The solutions are \(x = 0\), \(x = 5\), and \(x = -5\).
