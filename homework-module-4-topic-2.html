Problem 1

Let \(f(x)=\dfrac{x+7}{x-2}\). Find all \(x\) for which \(f(x)=4\).

Show all of your work.

We want the inputs that give an output of \(4\), so set \(f(x) = 4\).

\[ \frac{x+7}{x-2} = 4 \]

Clear the fraction by multiplying both sides by the denominator, \(x - 2\).

\[ x+7 = 4(x-2) \]

Distribute the \(4\), then get the \(x\) terms on one side and the numbers on the other.

\[ \begin{aligned} x+7 &= 4x-8 \\ 7+8 &= 4x-x \\ 15 &= 3x \\ 5 &= x \end{aligned} \]

Check. Clearing a fraction can create a false solution if the answer makes the denominator \(0\). Here \(x = 5\) gives a denominator of \(5 - 2 = 3\), which is fine, and

\[ f(5) = \frac{5+7}{5-2} = \frac{12}{3} = 4 \]

It checks. The answer is \(x = 5\).

Problem 2

Let \(f(x)=\sqrt{x+12}\). Find all \(x\) for which \(f(x)=x\).

Show all of your work.

Set \(f(x) = x\).

\[ \sqrt{x+12} = x \]

The square root is already by itself on one side, so square both sides to remove it.

\[ x+12 = x^2 \]

This is a quadratic equation. Move everything to one side so it equals \(0\), and factor. We need two numbers that multiply to \(-12\) and add to \(-1\): \(-4\) and \(3\).

\[ \begin{aligned} 0 &= x^2-x-12 \\ 0 &= (x-4)(x+3) \end{aligned} \]

Set each factor equal to \(0\): \(x = 4\) or \(x = -3\).

Check both answers in the original equation. Squaring both sides can create false solutions, so this step is required.

\(x = 4\): \(\sqrt{4+12} = \sqrt{16} = 4\), and the right side is also \(4\). It checks.

\(x = -3\): \(\sqrt{-3+12} = \sqrt{9} = 3\), but the right side is \(-3\). The square root symbol always means the positive root, and \(3\) does not equal \(-3\). So \(x = -3\) is a false solution and must be thrown out.

The answer is \(x = 4\).

Problem 3

Let \(f(x)=\sqrt{2x+7}+2\). Find all \(x\) for which \(f(x)=5\).

Show all of your work.

Set \(f(x) = 5\).

\[ \sqrt{2x+7}+2 = 5 \]

Before squaring, get the square root by itself. Subtract \(2\) from both sides.

\[ \sqrt{2x+7} = 3 \]

Now square both sides to remove the square root, and solve.

\[ \begin{aligned} 2x+7 &= 9 \\ 2x &= 2 \\ x &= 1 \end{aligned} \]

If we had squared before subtracting the \(2\), we would have had to square \(\sqrt{2x+7}+2\), which is much messier and easy to get wrong.

Check. \(f(1) = \sqrt{2(1)+7}+2 = \sqrt{9}+2 = 3+2 = 5\). It checks.

The answer is \(x = 1\).

Problem 4

Is the function a polynomial? If it is, state its degree.

  1. \(f(x)=6x^3-x+4\)
  2. \(f(x)=x^{2/3}+1\)
  3. \(f(x)=\dfrac{4}{x^2}\)
  4. \(f(x)=9-x^7\)

A function is a polynomial when every power of \(x\) is a whole number: \(0, 1, 2, 3, \ldots\). Write each term as a power of \(x\) and check the exponents. If it is a polynomial, the degree is the largest exponent.

  1. Yes, degree \(3\). The exponents are \(3\), \(1\) (since \(x = x^1\)), and \(0\) (since \(4 = 4x^0\)). All are whole numbers, and the largest is \(3\).
  2. No. The exponent \(\tfrac23\) is a fraction, not a whole number. Fractional exponents are roots in disguise: \(x^{2/3} = \sqrt[3]{x^2}\).
  3. No. Rewrite the fraction as a power: \(\dfrac{4}{x^2} = 4x^{-2}\). The exponent \(-2\) is negative, not a whole number. Any \(x\) in a denominator means it is not a polynomial.
  4. Yes, degree \(7\). The exponents are \(0\) and \(7\), both whole numbers. The degree is the largest exponent, \(7\), even though that term is written last.

Problem 5

Find the zeros and the intercepts of \(f(x)=x^3-2x^2-15x\). State each intercept as an ordered pair. State “none” where there are none.

Show all of your work.

Zeros. A zero is an input that gives an output of \(0\), so set \(f(x) = 0\).

\[ x^3-2x^2-15x = 0 \]

Every term has an \(x\), so factor out the greatest common factor \(x\) first.

\[ x(x^2-2x-15) = 0 \]

Now factor the trinomial. We need two numbers that multiply to \(-15\) and add to \(-2\): \(-5\) and \(3\).

\[ x(x-5)(x+3) = 0 \]

Set each factor equal to \(0\): \(x = 0\), \(x - 5 = 0\), and \(x + 3 = 0\).

Zeros: \(x = 0\), \(x = 5\), \(x = -3\)

\(x\)-intercepts. Each real zero \(c\) gives an \(x\)-intercept \((c,\,0)\): \((0,\,0)\), \((5,\,0)\), \((-3,\,0)\).

\(y\)-intercept. The \(y\)-intercept is where \(x = 0\). Put \(0\) into the original function: \(f(0) = 0 - 0 - 0 = 0\), so the \(y\)-intercept is \((0,\,0)\). The origin is both an \(x\)-intercept and the \(y\)-intercept, which happens whenever \(0\) is a zero.

Problem 6

Find the zeros and the intercepts of \(f(x)=x^3+5x^2-x-5\). State each intercept as an ordered pair. State “none” where there are none.

Show all of your work.

Zeros. Set \(f(x) = 0\).

\[ x^3+5x^2-x-5 = 0 \]

There are four terms and no common factor, so try factoring by grouping. Group the first two terms and the last two terms, and factor each group.

\[ x^2(x+5)-1(x+5) = 0 \]

Notice that we factored \(-1\) out of the second group, so that both groups contain the same factor \(x + 5\). Now factor out \(x + 5\).

\[ (x+5)(x^2-1) = 0 \]

The factor \(x^2 - 1\) is a difference of squares.

\[ (x+5)(x-1)(x+1) = 0 \]

Set each factor equal to \(0\).

Zeros: \(x = -5\), \(x = 1\), \(x = -1\)

\(x\)-intercepts. \((-5,\,0)\), \((1,\,0)\), \((-1,\,0)\)

\(y\)-intercept. The \(y\)-intercept is where \(x = 0\). Put \(0\) into the original function: \(f(0) = 0 + 0 - 0 - 5 = -5\), so the \(y\)-intercept is \((0,\,-5)\). For a polynomial, the \(y\)-intercept is always the constant term.

Problem 7

Find the zeros and the intercepts of \(f(x)=x^4-5x^2+4\). State each intercept as an ordered pair. State “none” where there are none.

Show all of your work.

Zeros. Set \(f(x) = 0\).

\[ x^4-5x^2+4 = 0 \]

This has the same pattern as a trinomial, with \(x^2\) in place of \(x\): think of it as \((x^2)^2 - 5(x^2) + 4\). We need two numbers that multiply to \(4\) and add to \(-5\): \(-1\) and \(-4\).

\[ (x^2-1)(x^2-4) = 0 \]

Both factors are differences of squares.

\[ (x-1)(x+1)(x-2)(x+2) = 0 \]

Set each factor equal to \(0\). A degree-4 polynomial can have up to four zeros, and this one has four real zeros.

Zeros: \(x = 1\), \(x = -1\), \(x = 2\), \(x = -2\)

\(x\)-intercepts. \((1,\,0)\), \((-1,\,0)\), \((2,\,0)\), \((-2,\,0)\)

\(y\)-intercept. The \(y\)-intercept is where \(x = 0\). Put \(0\) into the original function: \(f(0) = 0 - 0 + 4 = 4\), so the \(y\)-intercept is \((0,\,4)\).

Problem 8

Find all zeros of \(f(x)=x^3+16x\), including complex zeros. Then state the \(x\)-intercepts.

Show all of your work.

Set \(f(x) = 0\), and factor out the common factor \(x\).

\[ \begin{aligned} x^3+16x &= 0 \\ x(x^2+16) &= 0 \end{aligned} \]

The first factor gives \(x = 0\). The second factor, \(x^2 + 16\), is a sum of squares, which does not factor over the real numbers. Set it equal to \(0\) and solve by taking square roots.

\[ \begin{aligned} x^2+16 &= 0 \\ x^2 &= -16 \\ x &= \pm\sqrt{-16} \\ x &= \pm\sqrt{16}\cdot\sqrt{-1} \\ x &= \pm 4i \end{aligned} \]

Remember the \(\pm\): taking a square root gives two answers. And \(\sqrt{-1} = i\).

Zeros: \(x = 0\), \(x = 4i\), \(x = -4i\)

\(x\)-intercepts. Only real zeros are \(x\)-intercepts. The complex zeros \(\pm 4i\) are not on the graph, because the graph only has real \(x\)-values. So the only \(x\)-intercept is \((0,\,0)\).

Problem 9

Find all zeros of \(f(x)=x^4-1\), including complex zeros. Then state the \(x\)-intercepts.

Show all of your work.

Set \(f(x) = 0\). Since \(x^4 = (x^2)^2\) and \(1 = 1^2\), this is a difference of squares.

\[ \begin{aligned} x^4-1 &= 0 \\ (x^2-1)(x^2+1) &= 0 \end{aligned} \]

The first factor, \(x^2 - 1\), is another difference of squares.

\[ (x-1)(x+1)(x^2+1) = 0 \]

The factors \(x - 1\) and \(x + 1\) give \(x = 1\) and \(x = -1\). The last factor, \(x^2 + 1\), is a sum of squares and does not factor over the real numbers, so solve it by taking square roots.

\[ \begin{aligned} x^2+1 &= 0 \\ x^2 &= -1 \\ x &= \pm\sqrt{-1} \\ x &= \pm i \end{aligned} \]

Zeros: \(x = 1\), \(x = -1\), \(x = i\), \(x = -i\)

That is four zeros for a degree-4 polynomial, two real and two complex.

\(x\)-intercepts. Only the real zeros are \(x\)-intercepts: \((1,\,0)\) and \((-1,\,0)\).

Problem 10

Let \(f(x)=\begin{cases}x+3 & \text{if } x \lt 1\\ 5 & \text{if } x\ge1\end{cases}\). Find \(f(-2)\), \(f(1)\), and \(f(4)\).

For each input, first decide which piece it belongs to, then use that piece's formula.

\(f(-2)\): since \(-2 \lt 1\), use the first piece. \(f(-2) = -2 + 3 = 1\).

\(f(1)\): the first piece needs \(x \lt 1\), which does not include \(1\). The second piece needs \(x \ge 1\), which does. The second piece is the constant \(5\), so \(f(1) = 5\).

\(f(4)\): since \(4 \ge 1\), use the second piece. It is the constant \(5\), so \(f(4) = 5\).

Problem 11

Write \(\ln\left(\dfrac{x^3}{x+1}\right)\) as a sum and/or difference of logarithms. Express powers as factors.

Quotient rule. The log of a fraction is the log of the top minus the log of the bottom.

\[ = \ln x^3-\ln(x+1) \]

Power rule. Bring the power \(3\) down in front as a factor.

\[ = 3\ln x-\ln(x+1) \]

\(\ln(x+1)\) cannot be split any further. There is no rule for the log of a sum, so \(\ln(x+1)\) is not \(\ln x + \ln 1\).

Problem 12

Find the domain of \(f(x)=\sqrt{6-3x}\). State your answer in interval notation.

Show all of your work.

We cannot take the square root of a negative number, so the expression under the square root must be greater than or equal to \(0\). (It can equal \(0\), since \(\sqrt{0} = 0\).)

\[ 6-3x \ge 0 \]

Solve the inequality. Subtract \(6\) from both sides, then divide by \(-3\).

\[ \begin{aligned} -3x &\ge -6 \\ x &\le 2 \end{aligned} \]

When we divide both sides of an inequality by a negative number, the inequality sign flips, so \(\ge\) becomes \(\le\).

Check with a number: \(x = 0\) gives \(\sqrt{6}\), which is fine, and \(x = 3\) gives \(\sqrt{-3}\), which is not. That agrees with \(x \le 2\).

The domain is all \(x\) less than or equal to \(2\). In interval notation, \(2\) is included, so it gets a square bracket: \((-\infty,\,2]\).
