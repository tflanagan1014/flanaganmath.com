Problem 1

For \(f(x)=\dfrac{x+4}{x-6}\), find the domain, any holes, the vertical and horizontal asymptotes, and the intercepts. State asymptotes as equations, holes and intercepts as ordered pairs, and “none” where there are none.

Show all of your work.

Always start by factoring the top and bottom. Here they are already as simple as they can be, and they have no common factor, so nothing cancels.

Domain. The trouble spots are where the denominator is \(0\). Set \(x - 6 = 0\), so \(x = 6\). The domain is every real number except \(6\): \((-\infty,\,6)\cup(6,\,\infty)\).

Holes. A hole comes from a factor that cancels. Nothing cancels, so there are no holes.

Vertical asymptote. Since \(x = 6\) is a trouble spot that did not cancel, the graph has a vertical asymptote there: \(x = 6\).

Horizontal asymptote. Compare the degrees of the top and bottom. The top, \(x + 4\), has degree \(1\), and the bottom, \(x - 6\), also has degree \(1\). The degrees are equal, so the horizontal asymptote is \(y =\) the ratio of the leading coefficients. Both leading coefficients are \(1\), so \(y = \tfrac11 = 1\).

\(x\)-intercept. A fraction equals \(0\) only when its numerator is \(0\). Set \(x + 4 = 0\), so \(x = -4\). The \(x\)-intercept is \((-4,\,0)\).

\(y\)-intercept. Find \(f(0) = \dfrac{0+4}{0-6} = \dfrac{4}{-6} = -\dfrac23\). The \(y\)-intercept is \(\left(0,\,-\tfrac23\right)\).

Problem 2

For \(f(x)=\dfrac{5}{x^2-9}\), find the domain, any holes, the vertical and horizontal asymptotes, and the intercepts. State asymptotes as equations, holes and intercepts as ordered pairs, and “none” where there are none.

Show all of your work.

Start by factoring. The bottom is a difference of squares.

\[ f(x)=\frac{5}{(x-3)(x+3)} \]

Domain. The denominator is \(0\) when \(x - 3 = 0\) or \(x + 3 = 0\), so at \(x = 3\) and \(x = -3\). The domain is every real number except those two: \((-\infty,\,-3)\cup(-3,\,3)\cup(3,\,\infty)\).

Holes. The top is just \(5\), so there is no common factor to cancel. There are no holes.

Vertical asymptotes. Both trouble spots remain after simplifying, so there are two vertical asymptotes: \(x = 3\) and \(x = -3\).

Horizontal asymptote. The top, \(5\), is a constant, so it has degree \(0\). The bottom, \(x^2 - 9\), has degree \(2\). The top is smaller, so the horizontal asymptote is \(y = 0\). As \(x\) gets very large, the bottom grows huge while the top stays \(5\), so the fraction gets closer and closer to \(0\).

\(x\)-intercepts. A fraction is \(0\) only when its numerator is \(0\). The numerator is \(5\), which is never \(0\), so there are no \(x\)-intercepts.

\(y\)-intercept. Find \(f(0) = \dfrac{5}{0-9} = -\dfrac59\). The \(y\)-intercept is \(\left(0,\,-\tfrac59\right)\).

Problem 3

For \(f(x)=\dfrac{x-3}{x^2-9}\), find the domain, any holes, the vertical and horizontal asymptotes, and the intercepts. State asymptotes as equations, holes and intercepts as ordered pairs, and “none” where there are none.

Show all of your work.

Start by factoring. The bottom is a difference of squares.

\[ f(x)=\frac{x-3}{(x-3)(x+3)} \]

Domain. Find the domain before canceling anything. The denominator is \(0\) at \(x = 3\) and \(x = -3\), so the domain is \((-\infty,\,-3)\cup(-3,\,3)\cup(3,\,\infty)\). Even after a factor cancels, that \(x\)-value is still not in the domain.

Now simplify. The factor \(x - 3\) appears on top and bottom, so it cancels.

\[ f(x)=\frac{1}{x+3},\quad x\ne3 \]

Hole. The factor that canceled, \(x - 3\), gives a hole at \(x = 3\). To find its \(y\)-value, put \(x = 3\) into the simplified function: \(\dfrac{1}{3+3} = \dfrac16\). The hole is \(\left(3,\,\tfrac16\right)\). (Putting \(3\) into the original function would give \(\tfrac00\), which is why we use the simplified one.)

Vertical asymptote. The simplified denominator \(x + 3\) is \(0\) at \(x = -3\), so the vertical asymptote is \(x = -3\). There is no vertical asymptote at \(x = 3\), because that factor canceled and became a hole instead.

Horizontal asymptote. Compare degrees in the original function: the top, \(x - 3\), has degree \(1\), and the bottom, \(x^2 - 9\), has degree \(2\). The top is smaller, so \(y = 0\).

\(x\)-intercepts. Use the simplified numerator, which is \(1\). It is never \(0\), so there are no \(x\)-intercepts. The original numerator is \(0\) at \(x = 3\), but that is the hole, and an \(x\)-intercept never occurs at a hole.

\(y\)-intercept. Find \(f(0)\) using the simplified function: \(\dfrac{1}{0+3} = \dfrac13\). The \(y\)-intercept is \(\left(0,\,\tfrac13\right)\).

Problem 4

For \(f(x)=\dfrac{x^2-x-6}{x^2-4}\), find the domain, any holes, the vertical and horizontal asymptotes, and the intercepts. State asymptotes as equations, holes and intercepts as ordered pairs, and “none” where there are none.

Show all of your work.

Start by factoring. The top is a trinomial: we need two numbers that multiply to \(-6\) and add to \(-1\), which are \(-3\) and \(2\). The bottom is a difference of squares.

\[ f(x)=\frac{(x-3)(x+2)}{(x-2)(x+2)} \]

Domain. Find the domain before canceling. The denominator is \(0\) at \(x = 2\) and \(x = -2\), so the domain is \((-\infty,\,-2)\cup(-2,\,2)\cup(2,\,\infty)\).

Now simplify. The factor \(x + 2\) appears on top and bottom, so it cancels.

\[ f(x)=\frac{x-3}{x-2},\quad x\ne-2 \]

Hole. The factor that canceled, \(x + 2\), gives a hole at \(x = -2\). Put \(x = -2\) into the simplified function for its \(y\)-value: \(\dfrac{-2-3}{-2-2} = \dfrac{-5}{-4} = \dfrac54\). The hole is \(\left(-2,\,\tfrac54\right)\).

Vertical asymptote. The simplified denominator \(x - 2\) is \(0\) at \(x = 2\), so the vertical asymptote is \(x = 2\).

Horizontal asymptote. The top and bottom both have degree \(2\). The degrees are equal, so take the ratio of the leading coefficients. Both are \(1\), so \(y = 1\).

\(x\)-intercept. The simplified numerator \(x - 3\) is \(0\) at \(x = 3\), so the \(x\)-intercept is \((3,\,0)\). The original numerator is also \(0\) at \(x = -2\), but that is the hole, not an intercept.

\(y\)-intercept. Find \(f(0)\) using the simplified function: \(\dfrac{0-3}{0-2} = \dfrac{-3}{-2} = \dfrac32\). The \(y\)-intercept is \(\left(0,\,\tfrac32\right)\).

Problem 5

For \(f(x)=\dfrac{3x^2}{x^2+1}\), find the domain, any holes, the vertical and horizontal asymptotes, and the intercepts. State asymptotes as equations, holes and intercepts as ordered pairs, and “none” where there are none.

Show all of your work.

The bottom, \(x^2 + 1\), is a sum of squares and does not factor. In fact, it is never \(0\): since \(x^2 \ge 0\) for every \(x\), we always have \(x^2 + 1 \ge 1\).

Domain. The denominator is never \(0\), so there are no trouble spots. The domain is all real numbers, \((-\infty,\,\infty)\).

Holes. There are no trouble spots, so there are no holes.

Vertical asymptotes. There are no trouble spots, so there are no vertical asymptotes either.

Horizontal asymptote. The top and bottom both have degree \(2\). The degrees are equal, so take the ratio of the leading coefficients: \(y = \tfrac31 = 3\).

\(x\)-intercept. Set the numerator equal to \(0\): \(3x^2 = 0\) gives \(x = 0\). The \(x\)-intercept is \((0,\,0)\).

\(y\)-intercept. \(f(0) = \dfrac{0}{0+1} = 0\), so the \(y\)-intercept is \((0,\,0)\). The graph goes through the origin, so the origin is both intercepts.

Problem 6

For \(f(x)=\dfrac{x^2+4}{x+1}\), find the domain, any holes, the vertical and horizontal asymptotes, and the intercepts. State asymptotes as equations, holes and intercepts as ordered pairs, and “none” where there are none.

Show all of your work.

The top, \(x^2 + 4\), is a sum of squares and does not factor, and the bottom is already simple. There is no common factor, so nothing cancels.

Domain. The denominator is \(0\) at \(x = -1\). The domain is \((-\infty,\,-1)\cup(-1,\,\infty)\).

Holes. Nothing cancels, so there are no holes.

Vertical asymptote. The trouble spot \(x = -1\) did not cancel, so the vertical asymptote is \(x = -1\).

Horizontal asymptote. The top has degree \(2\) and the bottom has degree \(1\). The top is bigger, so there is no horizontal asymptote. As \(x\) gets very large, the top grows much faster than the bottom, so the graph does not level off at any height.

\(x\)-intercepts. Set the numerator equal to \(0\): \(x^2 + 4 = 0\) gives \(x^2 = -4\). No real number squared is negative, so there is no real solution, and there are no \(x\)-intercepts.

\(y\)-intercept. \(f(0) = \dfrac{0+4}{0+1} = 4\), so the \(y\)-intercept is \((0,\,4)\).

Problem 7

Let \(f(x)=\sqrt{x+2}\). Find all \(x\) for which \(f(x)=x\).

Show all of your work.

Set \(f(x) = x\).

\[ \sqrt{x+2} = x \]

The square root is already by itself, so square both sides.

\[ x+2 = x^2 \]

Move everything to one side so it equals \(0\), and factor. We need two numbers that multiply to \(-2\) and add to \(-1\): \(-2\) and \(1\).

\[ \begin{aligned} 0 &= x^2-x-2 \\ 0 &= (x-2)(x+1) \end{aligned} \]

Set each factor equal to \(0\): \(x = 2\) or \(x = -1\).

Check both answers in the original equation. Squaring both sides can create false solutions, so this step is required.

\(x = 2\): \(\sqrt{2+2} = \sqrt{4} = 2\), and the right side is also \(2\). It checks.

\(x = -1\): \(\sqrt{-1+2} = \sqrt{1} = 1\), but the right side is \(-1\). The square root symbol always means the positive root, and \(1\) does not equal \(-1\). So \(x = -1\) is a false solution and must be thrown out.

The answer is \(x = 2\).

Problem 8

Find the zeros of \(f(x)=x^3-9x\).

Show all of your work.

A zero is an input that gives an output of \(0\), so set \(f(x) = 0\).

\[ x^3-9x = 0 \]

Both terms have an \(x\), so factor it out first. Then \(x^2 - 9\) is a difference of squares.

\[ \begin{aligned} x(x^2-9) &= 0 \\ x(x-3)(x+3) &= 0 \end{aligned} \]

Set each factor equal to \(0\): \(x = 0\), \(x - 3 = 0\), and \(x + 3 = 0\). Don't forget the zero that comes from the factor \(x\) by itself.

Zeros: \(x = 0\), \(x = 3\), \(x = -3\)

Problem 9

Solve the equation \(\log_2(x+1)+\log_2(x-1)=3\).

Show all of your work.

Use the product rule to combine the two logs into one.

\[ \log_2\big((x+1)(x-1)\big) = 3 \]

Now there is a single log equal to a number, so rewrite it in exponential form. \(\log_2(\text{something}) = 3\) means \(2^3 = \text{something}\).

\[ (x+1)(x-1) = 2^3 \]

Multiply out the left side (it is a difference of squares) and solve by taking square roots.

\[ \begin{aligned} x^2-1 &= 8 \\ x^2 &= 9 \\ x &= \pm3 \end{aligned} \]

Check both in the original equation. We can only take the log of a positive number.

\(x = -3\): the terms would be \(\log_2(-2)\) and \(\log_2(-4)\), which are undefined. So \(x = -3\) is a false solution and must be thrown out.

\(x = 3\): \(\log_2 4 + \log_2 2 = 2 + 1 = 3\). It checks.

The solution is \(x = 3\).
