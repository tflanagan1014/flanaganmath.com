Problem 1

For \(f(x)=\dfrac{x+4}{x-6}\), find the domain, any holes, the vertical and horizontal asymptotes, and the intercepts. State asymptotes as equations, holes and intercepts as ordered pairs, and “none” where there are none.

Show all of your work.

Nothing factors, so nothing cancels.

Domain: the bottom is \(0\) at \(x=6\), so \((-\infty,\,6)\cup(6,\,\infty)\)

Holes: none

Vertical asymptote: \(x=6\)

Horizontal asymptote: the degrees are equal (both \(1\)), so \(y=\tfrac11=1\)

\(x\)-intercept: the numerator is \(0\) at \(x=-4\), so \((-4,\,0)\)

\(y\)-intercept: \(f(0)=\dfrac{4}{-6}=-\dfrac23\), so \(\left(0,\,-\tfrac23\right)\)

Problem 2

For \(f(x)=\dfrac{5}{x^2-9}\), find the domain, any holes, the vertical and horizontal asymptotes, and the intercepts. State asymptotes as equations, holes and intercepts as ordered pairs, and “none” where there are none.

Show all of your work.

Factor the bottom.

\[ f(x)=\frac{5}{(x-3)(x+3)} \]

Domain: the bottom is \(0\) at \(x=3\) and \(x=-3\), so \((-\infty,\,-3)\cup(-3,\,3)\cup(3,\,\infty)\)

Holes: none, since nothing cancels

Vertical asymptotes: \(x=3\) and \(x=-3\)

Horizontal asymptote: the top has degree \(0\) and the bottom has degree \(2\). The top is smaller, so \(y=0\).

\(x\)-intercepts: none, since the numerator \(5\) is never \(0\)

\(y\)-intercept: \(f(0)=\dfrac{5}{-9}=-\dfrac59\), so \(\left(0,\,-\tfrac59\right)\)

Problem 3

For \(f(x)=\dfrac{x-3}{x^2-9}\), find the domain, any holes, the vertical and horizontal asymptotes, and the intercepts. State asymptotes as equations, holes and intercepts as ordered pairs, and “none” where there are none.

Show all of your work.

Factor the bottom.

\[ f(x)=\frac{x-3}{(x-3)(x+3)} \]

Domain: the bottom is \(0\) at \(x=3\) and \(x=-3\), so \((-\infty,\,-3)\cup(-3,\,3)\cup(3,\,\infty)\).

The factor \(x-3\) cancels, so the simplified function is

\[ f(x)=\frac{1}{x+3},\quad x\ne3 \]

Hole: at \(x=3\). The simplified function gives \(\dfrac{1}{3+3}=\dfrac16\), so the hole is \(\left(3,\,\tfrac16\right)\).

Vertical asymptote: the simplified denominator is \(0\) at \(x=-3\), so \(x=-3\)

Horizontal asymptote: the top has degree \(1\) and the bottom has degree \(2\). The top is smaller, so \(y=0\).

\(x\)-intercepts: none, since the simplified numerator \(1\) is never \(0\)

\(y\)-intercept: \(f(0)=\dfrac{1}{0+3}=\dfrac13\), so \(\left(0,\,\tfrac13\right)\)

Problem 4

For \(f(x)=\dfrac{x^2-x-6}{x^2-4}\), find the domain, any holes, the vertical and horizontal asymptotes, and the intercepts. State asymptotes as equations, holes and intercepts as ordered pairs, and “none” where there are none.

Show all of your work.

Factor the top and bottom.

\[ f(x)=\frac{(x-3)(x+2)}{(x-2)(x+2)} \]

Domain: the bottom is \(0\) at \(x=2\) and \(x=-2\), so \((-\infty,\,-2)\cup(-2,\,2)\cup(2,\,\infty)\).

The factor \(x+2\) cancels, so the simplified function is

\[ f(x)=\frac{x-3}{x-2},\quad x\ne-2 \]

Hole: at \(x=-2\). The simplified function gives \(\dfrac{-2-3}{-2-2}=\dfrac{-5}{-4}=\dfrac54\), so the hole is \(\left(-2,\,\tfrac54\right)\).

Vertical asymptote: the simplified denominator is \(0\) at \(x=2\), so \(x=2\)

Horizontal asymptote: the degrees are equal (both \(2\)), and the leading coefficients are \(1\) and \(1\), so \(y=1\)

\(x\)-intercept: the simplified numerator is \(0\) at \(x=3\), so \((3,\,0)\)

\(y\)-intercept: \(f(0)=\dfrac{-3}{-2}=\dfrac32\), so \(\left(0,\,\tfrac32\right)\)

Problem 5

For \(f(x)=\dfrac{3x^2}{x^2+1}\), find the domain, any holes, the vertical and horizontal asymptotes, and the intercepts. State asymptotes as equations, holes and intercepts as ordered pairs, and “none” where there are none.

Show all of your work.

The bottom \(x^2+1\) is never \(0\), since \(x^2+1\ge1\).

Domain: \((-\infty,\,\infty)\)

Holes: none

Vertical asymptotes: none

Horizontal asymptote: the degrees are equal (both \(2\)), and the leading coefficients are \(3\) and \(1\), so \(y=\tfrac31=3\)

\(x\)-intercept: the numerator \(3x^2\) is \(0\) at \(x=0\), so \((0,\,0)\)

\(y\)-intercept: \(f(0)=0\), so \((0,\,0)\)

Problem 6

For \(f(x)=\dfrac{x^2+4}{x+1}\), find the domain, any holes, the vertical and horizontal asymptotes, and the intercepts. State asymptotes as equations, holes and intercepts as ordered pairs, and “none” where there are none.

Show all of your work.

Nothing factors, so nothing cancels.

Domain: the bottom is \(0\) at \(x=-1\), so \((-\infty,\,-1)\cup(-1,\,\infty)\)

Holes: none

Vertical asymptote: \(x=-1\)

Horizontal asymptote: the top has degree \(2\) and the bottom has degree \(1\). The top is bigger, so there is none.

\(x\)-intercepts: none, since \(x^2+4=0\) gives \(x^2=-4\), which has no real solution

\(y\)-intercept: \(f(0)=\dfrac{4}{1}=4\), so \((0,\,4)\)

Problem 7

Let \(f(x)=\sqrt{x+2}\). Find all \(x\) for which \(f(x)=x\).

Show all of your work.

Set \(f(x)=x\), square both sides, and solve.

\[ \begin{aligned} \sqrt{x+2} &= x \\ x+2 &= x^2 \\ 0 &= x^2-x-2 \\ 0 &= (x-2)(x+1) \end{aligned} \]

So \(x=2\) or \(x=-1\). Check each one in the original equation.

\(x=2\): \(\sqrt{4}=2\). It checks.

\(x=-1\): \(\sqrt{1}=1\), and \(1\ne-1\). This is a false solution.

The answer is \(x=2\).

Problem 8

Find the zeros of \(f(x)=x^3-9x\).

Show all of your work.

Set \(f(x)=0\). Factor out \(x\), then factor the difference of squares.

\[ \begin{aligned} x^3-9x &= 0 \\ x(x^2-9) &= 0 \\ x(x-3)(x+3) &= 0 \end{aligned} \]

Zeros: \(x=0\), \(x=3\), \(x=-3\)

Problem 9

Solve the equation \(\log_2(x+1)+\log_2(x-1)=3\).

Show all of your work.

Use the product rule to combine the logs, then write the equation in exponential form.

\[ \begin{aligned} \log_2\big((x+1)(x-1)\big) &= 3 \\ (x+1)(x-1) &= 2^3 \\ x^2-1 &= 8 \\ x^2 &= 9 \\ x &= \pm3 \end{aligned} \]

Check: \(x=-3\) gives \(\log_2(-2)\), which is undefined, so it is a false solution. \(x=3\) gives \(\log_2 4+\log_2 2=2+1=3\). It checks.

The solution is \(x=3\).
