Problem 1

Let \(f(x)=\dfrac{x+7}{x-2}\). Find all \(x\) for which \(f(x)=4\).

Show all of your work.

Set \(f(x)=4\) and clear the fraction by multiplying both sides by \(x-2\).

\[ \begin{aligned} \frac{x+7}{x-2} &= 4 \\ x+7 &= 4(x-2) \\ x+7 &= 4x-8 \\ 15 &= 3x \\ 5 &= x \end{aligned} \]

Check: \(f(5)=\dfrac{12}{3}=4\). It checks. The answer is \(x=5\).

Problem 2

Let \(f(x)=\sqrt{x+12}\). Find all \(x\) for which \(f(x)=x\).

Show all of your work.

Set \(f(x)=x\), square both sides, and solve.

\[ \begin{aligned} \sqrt{x+12} &= x \\ x+12 &= x^2 \\ 0 &= x^2-x-12 \\ 0 &= (x-4)(x+3) \end{aligned} \]

So \(x=4\) or \(x=-3\). Check each one in the original equation.

\(x=4\): \(\sqrt{16}=4\). It checks.

\(x=-3\): \(\sqrt{9}=3\), and \(3\ne-3\). This is a false solution.

The answer is \(x=4\).

Problem 3

Let \(f(x)=\sqrt{2x+7}+2\). Find all \(x\) for which \(f(x)=5\).

Show all of your work.

Set \(f(x)=5\). Get the square root by itself before squaring.

\[ \begin{aligned} \sqrt{2x+7}+2 &= 5 \\ \sqrt{2x+7} &= 3 \\ 2x+7 &= 9 \\ 2x &= 2 \\ x &= 1 \end{aligned} \]

Check: \(\sqrt{9}+2=5\). It checks. The answer is \(x=1\).

Problem 4

Is the function a polynomial? If it is, state its degree.

  1. \(f(x)=6x^3-x+4\)
  2. \(f(x)=x^{2/3}+1\)
  3. \(f(x)=\dfrac{4}{x^2}\)
  4. \(f(x)=9-x^7\)
  1. Yes. The degree is \(3\).
  2. No. The exponent \(\tfrac23\) is not a whole number.
  3. No. \(\dfrac{4}{x^2}=4x^{-2}\), and the exponent \(-2\) is not a whole number.
  4. Yes. The degree is \(7\).

Problem 5

Find the zeros and the intercepts of \(f(x)=x^3-2x^2-15x\). State each intercept as an ordered pair. State “none” where there are none.

Show all of your work.

Set \(f(x)=0\). Factor out \(x\), then factor the trinomial.

\[ \begin{aligned} x^3-2x^2-15x &= 0 \\ x(x^2-2x-15) &= 0 \\ x(x-5)(x+3) &= 0 \end{aligned} \]

Zeros: \(x=0\), \(x=5\), \(x=-3\)

\(x\)-intercepts: \((0,\,0)\), \((5,\,0)\), \((-3,\,0)\)

\(y\)-intercept: \(f(0)=0\), so \((0,\,0)\)

Problem 6

Find the zeros and the intercepts of \(f(x)=x^3+5x^2-x-5\). State each intercept as an ordered pair. State “none” where there are none.

Show all of your work.

Set \(f(x)=0\) and factor by grouping.

\[ \begin{aligned} x^3+5x^2-x-5 &= 0 \\ x^2(x+5)-1(x+5) &= 0 \\ (x+5)(x^2-1) &= 0 \\ (x+5)(x-1)(x+1) &= 0 \end{aligned} \]

Zeros: \(x=-5\), \(x=1\), \(x=-1\)

\(x\)-intercepts: \((-5,\,0)\), \((1,\,0)\), \((-1,\,0)\)

\(y\)-intercept: \(f(0)=-5\), so \((0,\,-5)\)

Problem 7

Find the zeros and the intercepts of \(f(x)=x^4-5x^2+4\). State each intercept as an ordered pair. State “none” where there are none.

Show all of your work.

Set \(f(x)=0\). This factors like a trinomial, with \(x^2\) in place of \(x\).

\[ \begin{aligned} x^4-5x^2+4 &= 0 \\ (x^2-1)(x^2-4) &= 0 \\ (x-1)(x+1)(x-2)(x+2) &= 0 \end{aligned} \]

Zeros: \(x=1\), \(x=-1\), \(x=2\), \(x=-2\)

\(x\)-intercepts: \((1,\,0)\), \((-1,\,0)\), \((2,\,0)\), \((-2,\,0)\)

\(y\)-intercept: \(f(0)=4\), so \((0,\,4)\)

Problem 8

Find all zeros of \(f(x)=x^3+16x\), including complex zeros. Then state the \(x\)-intercepts.

Show all of your work.

Set \(f(x)=0\) and factor out \(x\).

\[ \begin{aligned} x^3+16x &= 0 \\ x(x^2+16) &= 0 \end{aligned} \]

The first factor gives \(x=0\). For the second factor:

\[ \begin{aligned} x^2+16 &= 0 \\ x^2 &= -16 \\ x &= \pm\sqrt{-16} \\ x &= \pm 4i \end{aligned} \]

Zeros: \(x=0\), \(x=4i\), \(x=-4i\)

Only the real zero is an \(x\)-intercept: \((0,\,0)\).

Problem 9

Find all zeros of \(f(x)=x^4-1\), including complex zeros. Then state the \(x\)-intercepts.

Show all of your work.

Set \(f(x)=0\) and factor as a difference of squares.

\[ \begin{aligned} x^4-1 &= 0 \\ (x^2-1)(x^2+1) &= 0 \\ (x-1)(x+1)(x^2+1) &= 0 \end{aligned} \]

The first two factors give \(x=1\) and \(x=-1\). For the last factor:

\[ \begin{aligned} x^2+1 &= 0 \\ x^2 &= -1 \\ x &= \pm i \end{aligned} \]

Zeros: \(x=1\), \(x=-1\), \(x=i\), \(x=-i\)

Only the real zeros are \(x\)-intercepts: \((1,\,0)\) and \((-1,\,0)\).

Problem 10

Let \(f(x)=\begin{cases}x+3 & \text{if } x \lt 1\\ 5 & \text{if } x\ge1\end{cases}\). Find \(f(-2)\), \(f(1)\), and \(f(4)\).

  1. \(-2 \lt 1\), so use \(x+3\): \(\;f(-2)=-2+3=1\)
  2. \(1 \ge 1\), so use \(5\): \(\;f(1)=5\)
  3. \(4 \ge 1\), so use \(5\): \(\;f(4)=5\)

Problem 11

Write \(\ln\left(\dfrac{x^3}{x+1}\right)\) as a sum and/or difference of logarithms. Express powers as factors.

Use the quotient rule, then the power rule.

\[ \begin{aligned} &= \ln x^3-\ln(x+1) \\ &= 3\ln x-\ln(x+1) \end{aligned} \]

Problem 12

Find the domain of \(f(x)=\sqrt{6-3x}\). State your answer in interval notation.

Show all of your work.

The expression under the square root cannot be negative.

\[ \begin{aligned} 6-3x &\ge 0 \\ -3x &\ge -6 \\ x &\le 2 \end{aligned} \]

Dividing by \(-3\) flips the inequality. The domain is \((-\infty,\,2]\).
