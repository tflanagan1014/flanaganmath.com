  1. Find all vertical asymptotes, horizontal asymptotes, and holes of the rational function \(f(x)=\dfrac{2x+1}{x-3}\). State asymptotes as equations and holes as ordered pairs. State “none” where there are none.

    Nothing cancels. The denominator is \(0\) at \(x=3\), so the vertical asymptote is \(x=3\).

    The degrees of the top and bottom are equal, so the horizontal asymptote is the ratio of the leading coefficients: \(y=\dfrac{2}{1}=2\).

    Holes: none

  2. Find all vertical asymptotes, horizontal asymptotes, and holes of the rational function \(f(x)=\dfrac{3x^2-2}{x^2+x-6}\). State asymptotes as equations and holes as ordered pairs. State “none” where there are none.
    \[f(x)=\dfrac{3x^2-2}{(x+3)(x-2)}\]

    Nothing cancels, so the vertical asymptotes are \(x=-3\) and \(x=2\).

    The degrees are equal, so the horizontal asymptote is \(y=\dfrac{3}{1}=3\).

    Holes: none

  3. Find all vertical asymptotes, horizontal asymptotes, and holes of the rational function \(f(x)=\dfrac{x-4}{x^2-16}\). State asymptotes as equations and holes as ordered pairs. State “none” where there are none.
    \[f(x)=\dfrac{x-4}{(x-4)(x+4)}=\dfrac{1}{x+4}\quad (x\ne 4)\]

    The factor \(x-4\) cancels, so there is a hole at \(x=4\). Its \(y\)-value comes from the simplified form: \(\dfrac{1}{4+4}=\dfrac{1}{8}\). Hole: \(\left(4,\,\tfrac{1}{8}\right)\)

    Vertical asymptote: \(x=-4\)

    The bottom has the bigger degree, so the horizontal asymptote is \(y=0\).

  4. Find all vertical asymptotes, horizontal asymptotes, and holes of the rational function \(f(x)=\dfrac{x^2-9}{x^2-x-6}\). State asymptotes as equations and holes as ordered pairs. State “none” where there are none.

    The degrees are equal, so the horizontal asymptote is \(y=1\).

  6. Find the domain of the rational function \(f(x)=\dfrac{x+1}{x^2-5x-14}\). State your answer in interval notation.

    Domain: \(\left(-\infty,\,-\tfrac{3}{2}\right)\cup\left(-\tfrac{3}{2},\,1\right)\cup(1,\,\infty)\)

  8. Find the domain of the square root function \(f(x)=\sqrt{10-2x}\). State your answer in interval notation.

  6. Find the intercepts of the quadratic function \(f(x)=(x-3)^2-7\). State each intercept as an ordered pair. State “none” where there are none. Show all of your work.

    Use the square root property.

    \[\begin{aligned}(x-3)^2-7&=0\\ (x-3)^2&=7\\ x-3&=\pm\sqrt{7}\\ x&=3\pm\sqrt{7}\end{aligned}\]

    \(x\)-intercepts: \(\left(3+\sqrt{7},\,0\right)\) and \(\left(3-\sqrt{7},\,0\right)\).

    \(y\)-intercept: \(f(0)=(-3)^2-7=2\), so \((0,\,2)\).

  7. Find the intercepts of the quadratic function \(f(x)=x^2-6x+4\). State each intercept as an ordered pair. State “none” where there are none. Show all of your work.

    This does not factor, so use the quadratic formula with \(a=1\), \(b=-6\), \(c=4\).

    \[\begin{aligned}x&=\dfrac{6\pm\sqrt{(-6)^2-4(1)(4)}}{2(1)}\\ &=\dfrac{6\pm\sqrt{20}}{2}\\ &=\dfrac{6\pm2\sqrt{5}}{2}\\ &=3\pm\sqrt{5}\end{aligned}\]

    \(x\)-intercepts: \(\left(3+\sqrt{5},\,0\right)\) and \(\left(3-\sqrt{5},\,0\right)\). \(y\)-intercept: \((0,\,4)\).

  9. Find the intercepts of the polynomial function \(f(x)=x^3+2x^2-9x-18\). State each intercept as an ordered pair. State “none” where there are none. Show all of your work.

  1. The number of followers of a new social media account follows the law of exponential growth. Initially there are \(800\) followers. After \(3\) days there are \(2{,}000\) followers.
    1. Find \(k\) (round to four decimal places) and write the model.
    2. How many followers will there be after \(5\) days? Round to the nearest whole number.
    3. When will there be \(10{,}000\) followers? Round to two decimal places.

    1. Law of exponential growth: \(A(t)=A_0e^{kt}\), with \(A_0=800\).

      \[\begin{aligned}2000&=800e^{3k}\\ 2.5&=e^{3k}\\ 3k&=\ln 2.5\\ k&=\dfrac{\ln 2.5}{3}\approx0.3054\end{aligned}\]

      \(A(t)=800e^{0.3054t}\)

    2. \(A(5)=800e^{0.3054(5)}\approx3684\) followers
    3. \[\begin{aligned}800e^{0.3054t}&=10000\\ e^{0.3054t}&=12.5\\ 0.3054t&=\ln 12.5\\ t&=\dfrac{\ln 12.5}{0.3054}\approx8.27\end{aligned}\]

      About \(8.27\) days

  2. A radioactive substance follows the law of exponential decay. Initially there are \(50\) grams. After \(10\) years there are \(40\) grams.
    1. Find \(k\) (round to four decimal places) and write the model.
    2. How much will remain after \(25\) years? Round to the nearest tenth.
    3. Find the half-life. Round to the nearest tenth.

    1. \(A(t)=A_0e^{kt}\), with \(A_0=50\).

      \[\begin{aligned}40&=50e^{10k}\\ 0.8&=e^{10k}\\ 10k&=\ln 0.8\\ k&=\dfrac{\ln 0.8}{10}\approx-0.0223\end{aligned}\]

      \(A(t)=50e^{-0.0223t}\)

    2. \(A(25)=50e^{-0.0223(25)}\approx28.6\) grams

    3. Half of \(50\) is \(25\).

      \[\begin{aligned}50e^{-0.0223t}&=25\\ e^{-0.0223t}&=0.5\\ -0.0223t&=\ln 0.5\\ t&=\dfrac{\ln 0.5}{-0.0223}\approx31.1\end{aligned}\]

      About \(31.1\) years
