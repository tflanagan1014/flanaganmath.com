Find the domain. State your answer in interval notation.

  1. \(f(x)=\dfrac{x+1}{x^2-9}\)
    We can’t divide by zero, so set the denominator equal to zero and solve for \(x\).\[\begin{aligned}x^2-9&=0\\ x^2&=9\end{aligned}\]So \(x=3\) and \(x=-3\). These are the values that must be excluded from the domain.
    Domain: \((-\infty,-3)\cup(-3,3)\cup(3,\infty)\)
  2. \(g(x)=\sqrt{2x-8}\)
    We can’t take an even root of a negative number, so the expression inside the square root must be greater than or equal to zero. Solve the inequality.\[\begin{aligned}2x-8&\ge 0\\ 2x&\ge 8\\ x&\ge 4\end{aligned}\]Domain: \([4,\infty)\)
  3. \(h(x)=\ln(5-x)\)
    We can’t take the log of zero or a negative number, so the expression inside the \(\ln\) must be greater than zero. Solve the inequality.\[\begin{aligned}5-x&>0\\ -x&>-5\\ x&<5\end{aligned}\]When we divide both sides by \(-1\), the inequality sign flips.
    Domain: \((-\infty,5)\)
  4. \(k(x)=\dfrac{3}{\sqrt{x+2}}\)
    The square root is in the denominator, so both rules apply. The expression inside the square root must be greater than zero. Solve the inequality.\[\begin{aligned}x+2&>0\\ x&>-2\end{aligned}\]Domain: \((-2,\infty)\)
  5. \(m(x)=x^2-7x+1\)
    This function has no denominator, no even root, and no log, so no \(x\)-values break a rule. We can put in any real number.
    Domain: \((-\infty,\infty)\)
  6. \(p(x)=\dfrac{\sqrt{x-1}}{x-6}\)
    Two rules apply here.
    Even root: the expression inside the square root must be greater than or equal to zero.\[\begin{aligned}x-1&\ge 0\\ x&\ge 1\end{aligned}\]Denominator: set the denominator equal to zero and solve for \(x\).\[\begin{aligned}x-6&=0\\ x&=6\end{aligned}\]So \(x\) must be greater than or equal to \(1\), and \(x=6\) must be excluded.
    Domain: \([1,6)\cup(6,\infty)\)

Find all intercepts. State each one as an ordered pair.

  1. \(f(x)=2x-6\)
    \(y\)-intercept: make \(x\) zero.\[\begin{aligned}f(0)&=2(0)-6\\ &=-6\end{aligned}\]The \(y\)-intercept is \((0,-6)\).
    \(x\)-intercept: make \(f(x)\) zero and solve for \(x\).\[\begin{aligned}2x-6&=0\\ 2x&=6\\ x&=3\end{aligned}\]The \(x\)-intercept is \((3,0)\).
  2. \(g(x)=x^2-x-12\)
    \(y\)-intercept: make \(x\) zero.\[\begin{aligned}g(0)&=0^2-0-12\\ &=-12\end{aligned}\]The \(y\)-intercept is \((0,-12)\).
    \(x\)-intercepts: make \(g(x)\) zero and solve for \(x\).\[\begin{aligned}x^2-x-12&=0\\ (x-4)(x+3)&=0\end{aligned}\]\[\begin{aligned}x-4&=0\\ x&=4\end{aligned}\]\[\begin{aligned}x+3&=0\\ x&=-3\end{aligned}\]The \(x\)-intercepts are \((4,0)\) and \((-3,0)\).
  3. \(h(x)=\log_2(x+4)-3\)
    \(y\)-intercept: make \(x\) zero.\[\begin{aligned}h(0)&=\log_2(0+4)-3\\ &=\log_2 4-3\\ &=2-3\\ &=-1\end{aligned}\]Since \(2^2=4\), we have \(\log_2 4=2\). The \(y\)-intercept is \((0,-1)\).
    \(x\)-intercept: make \(h(x)\) zero and solve for \(x\).\[\begin{aligned}\log_2(x+4)-3&=0\\ \log_2(x+4)&=3\end{aligned}\]Convert from log form to exponential form.\[\begin{aligned}2^3&=x+4\\ 8&=x+4\\ x&=4\end{aligned}\]The \(x\)-intercept is \((4,0)\).
  4. \(k(x)=\log_6 x+\log_6(x+5)-2\)
    \(y\)-intercept: make \(x\) zero. We get \(\log_6 0\), but we can’t take the log of zero. Since \(x=0\) is not in the domain, there is no \(y\)-intercept.
    \(x\)-intercept: make \(k(x)\) zero and solve for \(x\).\[\begin{aligned}\log_6 x+\log_6(x+5)-2&=0\\ \log_6 x+\log_6(x+5)&=2\end{aligned}\]Use the product rule for logs to combine into one log.\[\begin{aligned}\log_6\big(x(x+5)\big)&=2\end{aligned}\]Convert from log form to exponential form.\[\begin{aligned}6^2&=x(x+5)\\ 36&=x^2+5x\\ x^2+5x-36&=0\\ (x+9)(x-4)&=0\end{aligned}\]\[\begin{aligned}x+9&=0\\ x&=-9\end{aligned}\]\[\begin{aligned}x-4&=0\\ x&=4\end{aligned}\]Check each answer in the original function. For \(x=-9\), we would need \(\log_6(-9)\), and we can’t take the log of a negative number, so \(x=-9\) is not a solution. For \(x=4\), both logs are defined.
    The \(x\)-intercept is \((4,0)\).
  5. \(m(x)=\lvert 2x-3\rvert-5\)
    \(y\)-intercept: make \(x\) zero.\[\begin{aligned}m(0)&=\lvert 2(0)-3\rvert-5\\ &=\lvert -3\rvert-5\\ &=3-5\\ &=-2\end{aligned}\]The \(y\)-intercept is \((0,-2)\).
    \(x\)-intercepts: make \(m(x)\) zero and solve for \(x\).\[\begin{aligned}\lvert 2x-3\rvert-5&=0\\ \lvert 2x-3\rvert&=5\end{aligned}\]The expression inside the absolute value can equal \(5\) or \(-5\). Solve each equation.\[\begin{aligned}2x-3&=5\\ 2x&=8\\ x&=4\end{aligned}\]\[\begin{aligned}2x-3&=-5\\ 2x&=-2\\ x&=-1\end{aligned}\]The \(x\)-intercepts are \((4,0)\) and \((-1,0)\).

Is each function even, odd, or neither? Show your work.

  1. \(f(x)=x^4-3x^2\)
    \[\begin{aligned}f(-x)&=(-x)^4-3(-x)^2\\ &=x^4-3x^2\\ &=f(x)\end{aligned}\]Since \(f(-x)=f(x)\), the function is even. Its graph is symmetric with respect to the \(y\)-axis.
  2. \(g(x)=2x^3-5x\)
    \[\begin{aligned}g(-x)&=2(-x)^3-5(-x)\\ &=-2x^3+5x\\ &=-(2x^3-5x)\\ &=-g(x)\end{aligned}\]Since \(g(-x)=-g(x)\), the function is odd. Its graph is symmetric with respect to the origin.
  3. \(h(x)=x^2+x\)
    Counterexample with \(x=1\):\[\begin{aligned}h(1)&=1^2+1\\ &=2\end{aligned}\]\[\begin{aligned}h(-1)&=(-1)^2+(-1)\\ &=0\end{aligned}\]\[\begin{aligned}-h(1)&=-2\end{aligned}\]Since \(h(-1)\) is not equal to \(h(1)\) and is not equal to \(-h(1)\), the function is neither even nor odd.
