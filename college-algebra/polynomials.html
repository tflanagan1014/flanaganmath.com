Module 4 – Topic 2

Working with Functions: Polynomials

The equation \(f(x)=k\) asks: which inputs \(x\) give the output \(k\)? On a graph, these are the \(x\)-values where the graph is at height \(k\).

To find them, set \(f(x)=k\) and solve for \(x\). Squaring both sides or clearing fractions can create false solutions, so always check your answers in the original equation.

Example 1

Let \(f(x)=\sqrt{x+6}\). Find all \(x\) for which \(f(x)=x\).

Set \(f(x)=x\), square both sides, and solve.

\[ \begin{aligned} \sqrt{x+6} &= x \\ x+6 &= x^2 \\ 0 &= x^2-x-6 \\ 0 &= (x-3)(x+2) \end{aligned} \]

So \(x=3\) or \(x=-2\). Check each one in the original equation.

\(x=3\): \(\sqrt{3+6}=\sqrt{9}=3\). It checks.

\(x=-2\): \(\sqrt{-2+6}=\sqrt{4}=2\), and \(2\ne-2\). This is a false solution.

The answer is \(x=3\).

A polynomial function is a sum of terms of the form \(ax^n\), where each exponent \(n\) is a whole number (\(0, 1, 2, 3, \ldots\)). For example, \(3x^4-2x+7\) is a polynomial. \(\sqrt{x}\) and \(\dfrac{2}{x}\) are not, because \(\sqrt{x}=x^{1/2}\) and \(\dfrac{2}{x}=2x^{-1}\).

The degree is the largest exponent. The degree of \(3x^4-2x+7\) is \(4\).

A zero of \(f\) is an input that gives the output \(0\), so we find zeros by setting \(f(x)=0\). Factor, then set each factor equal to \(0\).

A real zero \(c\) is where the graph crosses or touches the \(x\)-axis, at the \(x\)-intercept \((c,\,0)\). A complex zero is not on the graph, so it is not an \(x\)-intercept.

Example 2

Find the zeros and intercepts of \(f(x)=x^3-3x^2-4x+12\).

Set \(f(x)=0\) and factor by grouping.

\[ \begin{aligned} x^3-3x^2-4x+12 &= 0 \\ x^2(x-3)-4(x-3) &= 0 \\ (x-3)(x^2-4) &= 0 \\ (x-3)(x-2)(x+2) &= 0 \end{aligned} \]

Zeros: \(x=3\), \(x=2\), \(x=-2\)

\(x\)-intercepts: \((3,\,0)\), \((2,\,0)\), \((-2,\,0)\)

For the \(y\)-intercept, find \(f(0)=12\). The \(y\)-intercept is \((0,\,12)\).

Example 3

Find all zeros of \(f(x)=x^4-81\), including complex zeros. State the \(x\)-intercepts.

Set \(f(x)=0\) and factor as a difference of squares, twice.

\[ \begin{aligned} x^4-81 &= 0 \\ (x^2-9)(x^2+9) &= 0 \\ (x-3)(x+3)(x^2+9) &= 0 \end{aligned} \]

The first two factors give \(x=3\) and \(x=-3\). For the last factor:

\[ \begin{aligned} x^2+9 &= 0 \\ x^2 &= -9 \\ x &= \pm\sqrt{-9} \\ x &= \pm 3i \end{aligned} \]

Zeros: \(x=3\), \(x=-3\), \(x=3i\), \(x=-3i\)

Only the real zeros are \(x\)-intercepts: \((3,\,0)\) and \((-3,\,0)\).
